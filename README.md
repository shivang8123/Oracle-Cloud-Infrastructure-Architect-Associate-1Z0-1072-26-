##  Skills & Domains Validated

- Launching and managing bare metal and virtual **Compute** instances
- Configuring **Load Balancers** for traffic distribution and HA
- Architecting for **High Availability** and **security best practices**
- **Identity and Access Management (IAM)** — policies, compartments, dynamic groups
- **Advanced Networking** — VCNs, subnets, route tables, gateways, peering
- Working with **database services** (Data Guard, encryption, RAC, Exadata concepts)
- Designing and provisioning scalable, resilient OCI infrastructure end-to-end

##  How I Prepared

- Worked through **Oracle University's** official 1Z0-1072-26 learning path and exam topics
- Practiced hands-on with core OCI services (Compute, Networking, IAM) in the console
- Reinforced networking and security concepts using knowledge from my on-premise Kubernetes/Nutanix work, mapping familiar concepts (VLANs, RBAC, HA clustering) to their OCI equivalents
- Reviewed the official exam topic list closely and focused extra time on Advanced Networking and IAM, since these carry the most architectural weight
